# รูปห้อง 719

นำไฟล์รูปจริงของห้อง 719 มาวางในโฟลเดอร์นี้ เช่น:

- `719-1.jpg`
- `719-2.jpg`
- `719-3.jpg`
- `719-4.jpg`
- `719-5.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/719/719-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 719
