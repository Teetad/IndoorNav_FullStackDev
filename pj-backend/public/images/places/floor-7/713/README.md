# รูปห้อง 713

นำไฟล์รูปจริงของห้อง 713 มาวางในโฟลเดอร์นี้ เช่น:

- `713-1.jpg`
- `713-2.jpg`
- `713-3.jpg`
- `713-4.jpg`
- `713-5.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/713/713-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 713
