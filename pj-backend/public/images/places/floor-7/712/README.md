# รูปห้อง 712

นำไฟล์รูปจริงของห้อง 712 มาวางในโฟลเดอร์นี้ เช่น:

- `712-1.jpg`
- `712-2.jpg`
- `712-3.jpg`
- `712-4.jpg`
- `712-5.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/712/712-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 712
