# รูปห้อง 711

นำไฟล์รูปจริงของห้อง 711 มาวางในโฟลเดอร์นี้ เช่น:

- `711-1.jpg`
- `711-2.jpg`
- `711-3.jpg`
- `711-4.jpg`
- `711-5.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/711/711-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 711
