# รูปห้อง 700

นำไฟล์รูปจริงของห้อง 700 มาวางในโฟลเดอร์นี้ เช่น:

- `700-1.jpg`
- `700-2.jpg`
- `700-3.jpg`
- `700-4.jpg`
- `700-5.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/700/700-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 700
