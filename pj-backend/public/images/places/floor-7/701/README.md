# รูปห้อง 701

นำไฟล์รูปจริงของห้อง 701 มาวางในโฟลเดอร์นี้ เช่น:

- `701-1.jpg`
- `701-2.jpg`
- `701-3.jpg`
- `701-4.jpg`
- `701-5.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/701/701-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 701
