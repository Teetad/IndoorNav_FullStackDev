# รูปห้อง 718

นำไฟล์รูปจริงของห้อง 718 มาวางในโฟลเดอร์นี้ เช่น:

- `718-1.jpg`
- `718-2.jpg`
- `718-3.jpg`
- `718-4.jpg`
- `718-5.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/718/718-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 718
