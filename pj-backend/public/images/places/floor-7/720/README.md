# รูปห้อง 720

นำไฟล์รูปจริงของห้อง 720 มาวางในโฟลเดอร์นี้ เช่น:

- `720-1.jpg`
- `720-2.jpg`
- `720-3.jpg`

เมื่อ Backend ทำงาน Frontend เปิดรูปได้จาก URL เช่น:

```text
http://localhost:3000/images/places/floor-7/720/720-1.jpg
```

หลังวางไฟล์จริงแล้ว ให้เพิ่ม URL ผ่าน Place Images API เพื่อผูกภาพกับห้อง 720
