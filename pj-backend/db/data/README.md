# แผนที่อาคาร 30 ปี

ผู้ใช้ยืนยันชื่ออาคารว่า **อาคาร 30 ปี** และให้ใช้แผนที่ชั้น 4–7 เป็นแหล่งอ้างอิง
ข้อมูลที่ถอดไว้ใน `building30.ts` มี 78 สถานที่ (21 / 23 / 22 / 12 รายการตามชั้น)
ประเภทสถานที่เก็บใน `place_type`; ห้อง 712 ใช้ `null` เพราะยังไม่ยืนยันประเภท
รวมโถงลิฟต์ ห้องน้ำชาย ห้องน้ำหญิง และบันไดชั้นละหนึ่งรายการ
โถงลิฟต์เป็นจุดรวม ไม่ได้สร้างหมายเลขลิฟต์แต่ละตัว

## แหล่งข้อมูล

- ชั้น 4: `2028-4th-floor.pdf`
- ชั้น 5: `2028-5th-floor.pdf`
- ชั้น 6: `2028-6th-floor-v2.pdf`
- ชั้น 7: `IMG_5880.jpg` ใช้ชั้นตามข้อความเขียนและการยืนยันของผู้ใช้

ไฟล์ต้นฉบับอยู่ใน Downloads ของผู้ใช้ ไม่ได้เก็บใน repository หรือเผยแพร่ผ่าน API
`floor_plan_image` และ `image_url` ของรายการใหม่จึงเป็น null ไม่ใช้ path ในเครื่องเป็น URL

## สิ่งที่ยังไม่สร้างหรือยังไม่ยืนยัน

- ชั้น 4: พื้นที่ ป.ตรี หลายส่วน, staff, ห้องเก็บของ และข้อความเล็กบริเวณ 412s
  ยังไม่แยกเป็นรายการ เนื่องจากต้องยืนยันชื่อหรือขอบเขตแต่ละห้อง
- ชั้น 4 และ 6: เลข 1–9 และ 1–10 ของพื้นที่สีส้มเก็บเป็นป้ายกำกับในชื่อ
  ไม่ใส่ใน `room_number` และไม่สร้างเลข 401 / 601 ขึ้นเอง
- ชั้น 5: ห้องเก็บของที่ไม่มีชื่อเฉพาะยังไม่แยกเป็นรายการ
- ชั้น 7: เว้น 700 และพื้นที่วงแดงที่ไม่ทราบเลขหรือประเภท
  ห้อง 712 เก็บเลขได้ แต่ยังไม่ระบุประเภทห้อง
- ไม่เก็บตัวเลขความจุ เช่น 48, 96 เป็นเลขห้อง และไม่อนุมานความจุจากภาพ
- ไม่สร้างพิกัด ประตู ทางหนีไฟ หรือเส้นทางเดินจากภาพที่ยังไม่ได้สอบเทียบ

## การนำเข้า

```bash
# ดูข้อมูลก่อนนำเข้า ไม่ต้องเชื่อมฐานข้อมูล
pnpm seed:maps

# นำเข้าฐานข้อมูลที่ตั้งค่า environment ไว้และมี schema แล้ว
pnpm seed:maps --apply
```

นำเข้าภายใน transaction เดียว ใช้ UUID คงที่สำหรับรายการใหม่
รันซ้ำจะข้ามสถานที่ที่ตรง UUID ชื่อ หรือเลขห้องในชั้นเดียวกัน
ไม่เขียนทับข้อมูลสถานที่เดิม รวมทั้ง favCount และรูปภาพ
ใช้ชั้นเดิมตามอาคารและเลขชั้น จึงรักษา floor_id เดิมไว้
เปลี่ยนชื่ออาคารตัวอย่าง `30-Year Building` เป็น `อาคาร 30 ปี` เมื่อพบเพียงรายการเดียว
หากพบอาคารที่อาจตรงกันหลายรายการจะหยุดและ rollback เพื่อไม่รวมผิดอาคาร

สคริปต์นี้ไม่ลบ sample rooms 601–603 หรือข้อมูลอื่นที่มีอยู่เดิม
ต้องตรวจรายการเหล่านั้นแยกก่อนนำฐานข้อมูลไปใช้อ้างอิงจริง
คำสั่ง `pnpm seed` เดิมยังเป็นตัวอย่างที่ล้างทั้งสามตาราง อย่าใช้แทน `seed:maps`
การแก้ชุดข้อมูลในภายหลังจะไม่แก้แถวที่เคยนำเข้าแล้วโดยอัตโนมัติ
