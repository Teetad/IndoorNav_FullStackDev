# แผนที่อาคาร 30 ปี

ผู้ใช้ยืนยันชื่ออาคารว่า **อาคาร 30 ปี** และให้ใช้แผนที่ชั้น 4–7 เป็นแหล่งอ้างอิง
ข้อมูลที่ถอดไว้ใน `building30.ts` มี 81 สถานที่ (22 / 23 / 23 / 13 รายการตามชั้น)
ประเภทสถานที่เก็บใน `place_type`; ห้อง 712 ยืนยันแล้วว่าเป็นห้องเรียน
รวมโถงลิฟต์ ห้องน้ำชาย ห้องน้ำหญิง และบันไดชั้นละหนึ่งรายการ
โถงลิฟต์เป็นจุดรวม ไม่ได้สร้างหมายเลขลิฟต์แต่ละตัว

## แหล่งข้อมูล

- ชั้น 4: `ที่มา/2028-4th-floor.pdf`
- ชั้น 5: `ที่มา/2028-5th-floor.pdf`
- ชั้น 6: `ที่มา/2028-6th-floor-v2.pdf`
- ชั้น 7: `ที่มา/IMG_5880.jpg` ใช้ชั้นตามข้อความเขียนและการยืนยันของผู้ใช้

ไฟล์ต้นฉบับเก็บใน `db/data/ที่มา` และไม่ได้เผยแพร่ผ่าน API
`floor_plan_image` และ `places.image_url` ของรายการทั่วไปจึงเป็น null ไม่ใช้ path ในเครื่องเป็น URL
ส่วนห้องเรียนชั้น 7 จำนวน 9 ห้องมีรูปจริงห้องละ 5 รูป โดยเก็บ URL แบบ
`/images/places/floor-7/<เลขห้อง>/<ชื่อไฟล์>` ในตาราง `place_images`

## สิ่งที่ยังไม่สร้างหรือยังไม่ยืนยัน

- ชั้น 4: พื้นที่ ป.ตรี หลายส่วน, staff, ห้องเก็บของ และข้อความเล็กบริเวณ 412s
  ยังไม่แยกเป็นรายการ เนื่องจากต้องยืนยันชื่อหรือขอบเขตแต่ละห้อง
- ชั้น 4: ห้อง 422 ยืนยันว่าเป็นร้านค้าของสาขาวิศวกรรมคอมพิวเตอร์ มีขนมและสินค้า
- ชั้น 4 และ 6: เลข 1–9 และ 1–10 ของพื้นที่สีส้มเก็บเป็นป้ายกำกับในชื่อ
  ไม่ใส่ใน `room_number` และไม่สร้างเลข 401 / 601 ขึ้นเอง
- ชั้น 5: ห้องเก็บของที่ไม่มีชื่อเฉพาะยังไม่แยกเป็นรายการ
- ชั้น 6: เพิ่มธุรการภาควิชาวิศวกรรมคอมพิวเตอร์จากข้อมูลที่ผู้ใช้ยืนยัน
- ชั้น 7: พื้นที่วงแดงที่ไม่ทราบเลขหรือประเภทยังไม่ได้แยกเป็นรายการ
- ไม่เก็บตัวเลขความจุ เช่น 48, 96 เป็นเลขห้อง และไม่อนุมานความจุจากภาพ
- ไม่สร้างพิกัด ประตู ทางหนีไฟ หรือเส้นทางเดินจากภาพที่ยังไม่ได้สอบเทียบ
- ไม่ต้องเก็บรูปโถงลิฟต์ ห้องน้ำ และบันได เพราะใช้ Floor Plan ดูตำแหน่งได้

## การนำเข้า

```bash
# ดูข้อมูลก่อนนำเข้า ไม่ต้องเชื่อมฐานข้อมูล
pnpm seed:maps

# นำเข้าฐานข้อมูลที่ตั้งค่า environment ไว้และมี schema แล้ว
pnpm seed:maps --apply
```

นำเข้าภายใน transaction เดียว ใช้ UUID คงที่สำหรับรายการใหม่
รันซ้ำจะข้ามสถานที่ที่ตรง UUID ชื่อ หรือเลขห้องในชั้นเดียวกัน
หากรายการที่สคริปต์เคยนำเข้ายังไม่มี `place_type` จะเติมประเภทให้
ไม่แก้ประเภทของสถานที่ที่เพิ่มเอง และไม่เขียนทับชื่อ favCount หรือรูปภาพ
ใช้ชั้นเดิมตามอาคารและเลขชั้น จึงรักษา floor_id เดิมไว้
เปลี่ยนชื่ออาคารตัวอย่าง `30-Year Building` เป็น `อาคาร 30 ปี` เมื่อพบเพียงรายการเดียว
หากพบอาคารที่อาจตรงกันหลายรายการจะหยุดและ rollback เพื่อไม่รวมผิดอาคาร

สคริปต์นี้ไม่ลบข้อมูลอื่นที่มีอยู่เดิม และสามารถรันซ้ำได้
ข้อมูลตัวอย่างห้อง 601–603 และคำสั่ง `pnpm seed` ถูกลบแล้ว เพราะไม่ตรงกับแผนที่จริง
สคริปต์เติมประเภท สถานะ ความจุ และเวลาให้รายการเดิมเมื่อฐานข้อมูลยังไม่มีค่า
seed จะเพิ่ม URL รูปชั้น 7 ที่ยังไม่มี และ unique index ป้องกันรูปซ้ำเมื่อรันอีกครั้ง
แต่ไม่ลบรูป ไม่เขียนทับชื่อ หรือ `favCount` ที่มีคนแก้ผ่านระบบแล้ว
